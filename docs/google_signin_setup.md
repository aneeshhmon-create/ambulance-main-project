# Google Cloud & OAuth 2.0 Sign-In Setup Guide

This guide walks you through configuring Google Cloud OAuth 2.0 credentials for the **Ambulance Driver Flutter App** and the **FastAPI Backend**.

---

## 1. Create a Google Cloud Project

1. Go to the [Google Cloud Console](https://console.cloud.google.com/).
2. Click the project dropdown at the top-left and select **New Project**.
3. Set the **Project Name** to `Ambulance-Driver-Auth` (or your preferred name).
4. Click **Create** and ensure the new project is selected in the top bar.

---

## 2. Configure OAuth Consent Screen

1. In the left navigation menu, go to **APIs & Services** > **OAuth consent screen**.
2. Select **External** user type and click **Create**.
3. **App Information**:
   * **App name**: `Ambulance Driver Portal`
   * **User support email**: Select your Google email address.
   * **Developer contact email**: Enter your team lead's email.
   * Click **Save and Continue**.
4. **Scopes**:
   * Click **Add or Remove Scopes**.
   * Check:
     * `.../auth/userinfo.email`
     * `.../auth/userinfo.profile`
     * `openid`
   * Click **Update** then **Save and Continue**.
5. **Test Users (Crucial for Testing Mode)**:
   * Click **+ Add Users**.
   * Add all Gmail addresses of teammates and demo drivers (e.g. `driver1@gmail.com`, your personal Gmail accounts).
   * *Note: Accounts not added as test users will be blocked with a `403 access_denied` error until published to Production.*
   * Click **Save and Continue**.

---

## 3. Create Web OAuth Client ID (Backend & Flutter Server Client)

This client ID is used by:
- The FastAPI backend to verify ID tokens.
- The Flutter driver app as the `serverClientId` to obtain a backend-verifiable ID token.

1. Navigate to **APIs & Services** > **Credentials**.
2. Click **+ Create Credentials** > **OAuth client ID**.
3. Under **Application type**, choose **Web application**.
4. Set **Name** to: `Ambulance Web & Backend Client`.
5. Under **Authorized redirect URIs**, add:
   * `http://localhost:8000/auth/google`
   * `https://developers.google.com/oauthplayground` (useful for manual token debugging)
6. Click **Create**.
7. Copy the generated **Client ID** (e.g., `123456789-abcdef.apps.googleusercontent.com`).

---

## 4. Create Android OAuth Client ID (Driver Mobile App)

The `google_sign_in` plugin on Android requires an Android OAuth client ID linked to the package name and your machine's debug SHA-1 signing fingerprint.

### 4.1 Get Your Debug Keystore SHA-1 Fingerprint
Each teammate has a unique local debug keystore generated by Android Studio/Gradle. Every developer must obtain their SHA-1:

Open PowerShell or terminal in the `flutter_app/android` directory:
```bash
cd flutter_app/android
./gradlew signingReport
```
Look for the `Variant: debugAndroidTest` or `Task :app:signingReport` output under `Variant: driverDebug`:
```text
Variant: driverDebug
Config: debug
Store: C:\Users\<Username>\.android\debug.keystore
Alias: AndroidDebugKey
SHA1: AA:BB:CC:DD:EE:FF:00:11:22:33:44:55:66:77:88:99:00:11:22:33
```
*(Alternative using keytool)*:
```bash
keytool -list -v -keystore "%USERPROFILE%\.android\debug.keystore" -alias androiddebugkey -storepass android -keypass android
```

### 4.2 Create Android Credentials in Google Cloud
1. In Google Cloud Console, go to **Credentials** > **+ Create Credentials** > **OAuth client ID**.
2. Under **Application type**, choose **Android**.
3. Set **Name** to: `Ambulance Driver Android (Teammate Name)`.
4. Set **Package name** to:
   ```text
   com.team19.ambulance.driver
   ```
   *(Defined in `flutter_app/android/app/build.gradle.kts` under `driver` flavor)*.
5. Paste your **SHA-1 certificate fingerprint**.
6. Click **Create**.
7. **Note for teammates**: Repeat this step for each developer's machine by creating an additional Android OAuth Client ID with their machine's respective SHA-1 and the same package name `com.team19.ambulance.driver`.

## 5. Where Each Value Goes

### 5.1 Backend (`.env`)
In the root `.env` file (copied from `.env.example`):
```env
# Google OAuth 2.0 Web Client ID (from Step 3)
GOOGLE_CLIENT_ID=1234567890-abcdefg123456.apps.googleusercontent.com

# JWT Configuration
JWT_SECRET=supersecret-random-hex-string-for-ambulance-jwt-auth
JWT_EXPIRE_MINUTES=1440

# Optional: set to true to test without Google auth via POST /auth/dev-login
ALLOW_DEV_LOGIN=false
```

### 5.2 Seeding Demo Drivers
In `seed_demo_drivers.py`, replace placeholder emails with your actual test Gmail accounts:
```python
DEMO_DRIVERS = [
    {
        "name": "Your Name",
        "email": "your_test_account@gmail.com",  # <-- Put your Google account email here
        "phone": "+919876543210",
        "is_active": True,
    },
    ...
]
```
Run the seed script:
```bash
docker exec ambulance_app python seed_demo_drivers.py
```

### 5.3 Flutter Driver App (Build / Run Flags)
Pass the Web Client ID as `GOOGLE_SERVER_CLIENT_ID` and your backend host as `API_BASE_URL`:

**Android (LAN / Physical Device / Emulator)**:
```bash
flutter run --flavor driver -t lib/driver_app/main.dart \
  --dart-define=API_BASE_URL=http://10.0.2.2:8000 \
  --dart-define=GOOGLE_SERVER_CLIENT_ID=1234567890-abcdefg123456.apps.googleusercontent.com
```

**Web**:
```bash
flutter run -d chrome -t lib/driver_app/main.dart \
  --dart-define=API_BASE_URL=http://localhost:8000 \
  --dart-define=GOOGLE_SERVER_CLIENT_ID=1234567890-abcdefg123456.apps.googleusercontent.com
```
